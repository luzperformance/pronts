# Frontend incorporado em fatias verticais

O frontend será incorporado por fatias verticais orientadas aos fluxos do
usuário, começando pela autenticação e avançando gradualmente pelos fluxos
clínicos.

Cada fatia copiará do repositório-base somente os componentes e testes
necessários naquele momento, adaptará a integração ao contrato da API Spring e
terminará funcionando de ponta a ponta. A interface inteira não será copiada
antecipadamente, e código sem uso comprovado ficará fora do novo frontend.
