# Frontend no monorepo

O frontend web será mantido em `frontend/` neste mesmo repositório, ao lado do
backend Spring Boot. Serão copiados do repositório-base somente a aplicação
React/Vite, os componentes e os testes que forem efetivamente reutilizáveis.

Não fazem parte da migração o servidor Express, o banco de dados próprio nem os
scripts de implantação do repositório-base. O repositório original permanecerá
intacto e será usado apenas como referência.
