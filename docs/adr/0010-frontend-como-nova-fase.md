# Frontend como nova fase do produto

O frontend web será especificado e implementado como uma nova fase do produto,
sem reabrir o escopo nem os 22 tickets aprovados para o backend. A API Spring e
seu contrato OpenAPI permanecem como fronteira já aprovada; mudanças no backend
só serão admitidas quando a integração revelar defeito ou lacuna indispensável,
e não por conveniência da interface.
